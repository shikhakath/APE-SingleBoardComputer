# The power planes, drawn by hand: straight edges, each voltage on its own layer. Edit this file and run
#     python planes.py check       what each region reaches, and what is left for tracks; out/plane_L4.png, plane_L5.png
#     python planes.py apply       writes it to the PcbDoc (take the Altium lock)
#
#     LAYER RAIL  rect x1 y1 x2 y2
#     LAYER RAIL  poly x,y x,y x,y ...      corners in order, mm from the board's lower-left corner
#     LAYER RAIL  board                     the whole board
#
# Poured in file order, and each pours around the ones before it on its layer. So an island goes first, and the rail that
# fills the rest of the layer last. A corner on the board's edge is pulled in and chamfered to clear the outline.
#
# L5 is the 3.3 V layer: VCC_3V3_SYS everywhere, with an island where another rail has its own block of parts.
# L4 holds the rest: 5 V west and north-west, 1.8 V east and south, core and DDR in the middle.
# A rail with few pads and little current has no region of its own: planes.py gives it a straight strip on L4 or L5, and the
# plane there pours around it. Only if neither plane layer can do it does it get a track on a signal layer.
